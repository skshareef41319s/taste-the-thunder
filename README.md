# Thums Up Cinematic Storytelling

A premium single-page storytelling experience built with React, Vite, Tailwind CSS, GSAP ScrollTrigger, Framer Motion, Lenis, and synthesized optional audio cues.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- The provided cinematic source video is served from `public/thums-up-cinematic.mp4`.
- The app reuses that source across all nine story beats and layers different motion treatment per section.
- Audio is synthesized client-side and muted by default.
